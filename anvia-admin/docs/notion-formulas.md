# 予安所託 — Notion 公式全集 (2026-11-10 由瀏覽器逐字抄錄, 唯讀, 未修改 Notion)

## 訂單內容明細
- 訂單編號 = formatDate(建立時間, "YYYYMMDD") + "-" + (if(toNumber(ID) < 10, "00", if(toNumber(ID) < 100, "0", "")) + format(ID))
- 單位利潤 = 代購單價*0.065
- 應A運費-巧 = ceil(抵台批次（集運包）.map(current.分攤運費-巧郎).max()*包裹重量kg)
- 國際運費-台集運 = ceil(抵台批次（集運包）.map(current.分攤運費-台集運).max()*包裹重量kg)
- 欠款拉取 = if(欠款>0, 欠款, 0)
- make = id().substring(0, 8) + "-" + id().substring(8, 12) + "-" + id().substring(12, 16) + "-" + id().substring(16, 20) + "-" + id().substring(20)
- 應A運費（舊） = ceil(抵台批次（集運包）.map(current.單位重量應A運費（舊）).max()*包裹重量kg)

## 出貨對帳表
- 本單總價（含運費） = 物品總額+運費 | 總（舊）
- 本單利潤 = hx|r.map(current.XfVp).sum()
- 物品總額 = 訂單內容明細.map(current.單位利潤).sum()
- 物品重量kg = 訂單內容明細.map(current.包裹重量kg).sum()
- 基礎運費 | A費-台集運 = 訂單內容明細.map(current.應A運費-巧).sum()
- 基礎運費 | A費-巧郎 = 訂單內容明細.map(current.應A運費-巧).sum()
- 基礎運費 | A費（舊） = 訂單內容明細.map(current.應A運費（舊）).sum()
- 總二補-好賣+ = if((基礎運費|A費-台集運 + 運費|辛苦費 + 15 + Σ欠款) < 25, 25, ceil(同式))
- 總二補-賣貨便 = if((基礎運費|A費-台集運 + 運費|辛苦費 + 15 + Σ欠款) < 20, 20, ceil(同式))
- 運費 | 總（舊） = if((基礎運費|A費（舊） + 運費|辛苦費 + 15) < 20, 20, ceil(同式))
- 運費 | 辛苦費 = 包裹數量級距 (<4:0, <7:10, <10:25, <12:40, else 50) + 物品重量kg級距 (<1:0, <2:5, <3:15, <4:35, <5:50, else 60)
- 包裹數量 = if(實際包裹數量>0, 實際包裹數量, length(unique(訂單內容明細.map(current.商品名稱))))

## 抵台批次（集運包）
- 巧巧郎運費 = ceil(實際重量kg)*73
- 台集運總運費 = ceil((ceil(實際重量kg*2)/2)*73)
- 分攤運費-台集運 = ceil((台集運總運費/實際重量kg*100)/100) (= ceil(每kg均攤))
- 分攤運費-巧郎 = ceil((巧巧郎運費/實際重量kg*100)/100)
- 單位重量應A運費（舊） = ceil((巧巧郎運費/總包裹重量*100)/100)
- 运费（舊） = ceil(實際重量kg)*53
- date = formatDate(下單时间, "YYYYMMDD")

## 客戶檔案
- 進行中 = 匯總-用來分組!= "取消/已退款" and 匯總-用來分組!= "已寄出"
- 待出貨商品 = if(empty(訂單內容（新）.filter(current.狀態 == "已抵台")), false, true)
- 未歸檔訂單 = 訂單內容明細.filter(current.狀態!="已寄出")
- 客戶總結 = lets(獲利=出貨對帳表（新）.map(本單利潤).filter(>0).sum(), 找不到=已出貨且包裹為空, 未到=未到貨, 寄出=已寄出, 最後交易/最新=上次代購日期...) 輸出 "獲利 元 / N 筆未出貨 / 寄出 N 筆 / 最後交易 YYYY-MM-DD"
- notion id = id()

## 匯總統計
- 匯總 = 標題欄 (非公式)
- 總結 = "------本月------" + 本月獲客 (客戶檔案.客戶暱稱 count) + 訂單金額 (訂單及包裹管理.物品總額 sum) + 利潤約 (本單利潤 sum), 帶樣式
