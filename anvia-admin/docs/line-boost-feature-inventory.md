# LINE Boost 功能盤點（2026-11-10，來源 boost.gentlerdigit.com 首頁＋/line-message）

LINE Boost = 柔兒數位（Gentler Digit）的 LINE 官方帳號訊息內容中心（付費 SaaS，年度授權）。
樂生要求比照其全部功能做一套自己的工具，併入後台 LINE 模組，獨立部署時一起搬過去。

## 功能清單
1. 圖文選單編輯器：拖曳切格、任意座標熱區、20+ 產業範本、大張 2500×1686／小張 2500×843、多層切換（rich menu switch）、排程上下架、分眾選單（依 UID/標籤指派不同選單、CSV 匯入名單、解除指派回預設）
2. 訊息管理（8 種格式，同一編輯器通用於自動回覆/歡迎/推播）：純文字（{{name}} 變數）、純圖片、熱區圖片（imagemap）、純影片、YouTube 卡片（貼網址自動抓縮圖＋播放卡）、單頁 Flex、多頁 Flex（≤12 張）、範本訊息（按鈕/確認/圖片輪播）；每則可加 Quick Reply（≤13 顆）＋隨附文字訊息
3. 訊息範本庫：選單/卡片/YouTube 卡存範本，跨官方帳號套用
4. 自動回覆：關鍵字完全/包含比對、多同義詞、啟停、觸發次數統計、回覆可並發多則、走 reply API 不計額度
5. 自動貼標：3 種觸發（關鍵字、選單格、訊息按鈕）；標籤人數/引用次數、色彩管理
6. 分眾推播：標籤 AND/OR＋排除名單、指定 ID、全部好友；立即/排程/測試發送；額度守門（送出前比對剩餘則數，不夠擋下並顯示差幾則）；失敗自動重試一次
7. 成效分析：KPI 儀表板（7/14/30/90 天）、推播漏斗（LINE Insight 送達/觸及/點擊/CTR）、受眾輪廓、點擊熱區 Top10＋最近點擊清單（時間/用戶/URL）、AI 每週洞察
8. 分享擴散（MGM）：訊息加「分享給好友」按鈕（shareTargetPicker）、漏斗追蹤（開啟/送出/取消）、最常分享排行
9. 歡迎流程：最多 3 則連發、{{name}} 帶入暱稱、封鎖後加回是否重發
10. 多官方帳號管理：一介面切換、範本共用、標籤/配額/成效各自隔離
11. 活動報名：LINE 內表單、匯款回報、人工審核、場次名額、開課前提醒
12. 問卷：單選/複選/評分/文字、每人限填一次、完成自動發共用連結或一人一碼序號、CSV 匯出
13. 小遊戲＋獎勵池：轉盤/刮刮樂/拉霸/每日抽籤/心理測驗；獎勵池管機率/庫存/券碼/現場核銷；玩過自動貼標；集章尋寶（進階）
14. 自動旅程：加好友/被貼標/活動結束觸發，分天送訊息＋貼標；分支、生日、沉睡喚醒（進階）
15. 來源追蹤連結：每通路一條加好友連結，自動貼來源標籤，統計各通路新好友數
16. 會員資料庫（進階）：手機合併一戶多人、本人綁定、分群推播
17. 點數與會員卡（進階）：等級門檻自動升級、現場掃會員卡集點
18. 進階推播（進階）：貼 Flex JSON 直送、送審核准流程（退回寫原因）、警語自動附
19. API 與 AI 助理（進階）：AI 對話做草稿、人按上線；事件通知、團隊子帳號

## 技術前提（重要）
- 編輯/手動發送類（1–3、9、10 部分）：Messaging API 即可，現在的後台就能做
- Webhook 類（4、5、7 的點擊、8、14、15）：需要公開 Webhook 端點接收 LINE 事件——Muse 空間沒有公開網址，
  必須等獨立部署（Netlify Functions）後才能做；分眾選單依標籤即時指派也屬此類
- LIFF 應用類（11、12、13、16、17）：需要 LIFF 頁＋後端，獨立部署後做
- LINE 不提供個人層級已讀率，任何版本都不做假數據

## 建置分期（建議）
- A 期（編輯器全套）：8 種訊息編輯器＋Quick Reply＋隨附文字、選單 20+ 範本與多層/排程、歡迎流程、範本庫
- B 期（部署後 Webhook）：自動回覆引擎、自動貼標、點擊追蹤＋成效儀表板、分眾推播＋額度守門、分眾選單、分享擴散
- C 期（應用）：活動報名、問卷、小遊戲＋獎勵池、自動旅程、來源追蹤、會員/點數
