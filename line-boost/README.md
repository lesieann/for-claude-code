# LINE Boost 工具

參考 [LINE Boost](https://boost.gentlerdigit.com/line-message) 的功能，自架的 LINE 官方帳號工具：視覺化編輯訊息、多層圖文選單、自動貼標籤、標籤分眾推播與點擊成效。透過 LINE 官方的 Messaging API 操作你自己的官方帳號。

Node.js 18 以上即可執行，不需要安裝任何套件。

## 功能

| 功能 | 說明 |
|---|---|
| 8 種訊息格式 | 純文字、純圖片、熱區圖片（拖曳切格）、純影片、YouTube 卡片、單頁／多頁圖文訊息（Flex）、按鈕／確認範本、自訂 Flex JSON |
| 快速回覆 | 任何訊息底下最多 13 個，可放小圖示、開連結、分享給好友、貼標籤、開相機／相簿／位置 |
| YouTube 卡片 | 貼網址自動產生縮圖＋播放鈕卡片，點開在 LINE 內全螢幕播放 |
| 圖片處理 | 上傳後自動縮圖、壓縮；熱區圖片自動產生 1040／700／460／300／240 五種尺寸；影片自動擷取預覽圖 |
| 多層圖文選單 | 大張 2500×1686／小張 2500×843、拖曳切格、格子動作（開連結、傳文字、切換到其他層、貼標籤、分享），可用格子文字自動產生底圖 |
| 分眾選單 | 選單只指派給特定標籤的好友；之後被貼上該標籤的好友自動換上 |
| 排程 | 推播排程、圖文選單排程上架／下架 |
| 自動貼標籤 | 好友點圖文選單格子、按鈕、快速回覆、追蹤連結，或傳關鍵字時自動貼標籤 |
| 標籤分眾推播 | 標籤 AND／OR 組合、排除名單、即時顯示符合人數；也可推播全部好友或測試對象 |
| 點擊成效 | 每次推播每顆按鈕、圖文選單每一格的點擊數與不重複人數 |
| 範本 | 存成範本後重複使用，跨你管理的所有官方帳號共用 |
| 歡迎訊息／關鍵字自動回覆 | 用範本當回覆內容，可同時貼標籤 |
| 多帳號管理 | 一套工具管理多個官方帳號 |
| 推播額度 | 查詢本月額度與已使用量 |
| 手機預覽與 JSON | 即時手機預覽、檢視／複製 LINE JSON、送 LINE 驗證格式 |

### 關於「LINE 標籤」

LINE 官方帳號後台的「聊天標籤」無法透過 Messaging API 讀取或寫入，所以本工具（和 LINE Boost 一樣）自己維護標籤：

1. 好友點了設成「貼標籤」的按鈕／選單格子（postback），或點了追蹤連結 → Webhook 收到 → 自動貼標籤。
2. 「好友與標籤」頁可以手動批次貼標籤或移除標籤。
3. 推播時用標籤 AND／OR／排除組合篩出名單，用 multicast 發送；開啟「追蹤點擊」時改為逐人發送，才能知道是誰點了連結。

## 安裝與啟動

```bash
cd line-boost
cp .env.example .env   # 編輯 PUBLIC_URL 與 ADMIN_PASSWORD
npm start              # 預設 http://localhost:3000，帳號 admin
```

LINE 只接受 **HTTPS 公開網址**的圖片與 Webhook，所以正式使用要部署到有網域的主機（如 Render、Railway、Fly.io、VPS），並把網址設為 `PUBLIC_URL`。本機測試可以用 `cloudflared tunnel --url http://localhost:3000` 或 ngrok 取得暫時的 HTTPS 網址。

資料存在 `data/`（`db.json` 與上傳的圖片），部署時請掛載持久化磁碟，並定期備份。

## 連接官方帳號

1. 到 [LINE Developers Console](https://developers.line.biz/console/) 選擇官方帳號的 Messaging API channel。
2. 「Basic settings」複製 **Channel secret**；「Messaging API」頁最下方發行 **Channel access token (long-lived)**。
3. 在工具「帳號設定」新增帳號，複製畫面上的 Webhook URL（`https://你的網域/webhook/<帳號代碼>`）。
4. 貼到 Developers Console 的「Messaging API → Webhook URL」，開啟 **Use webhook**，按 Verify。
5. 在 LINE 官方帳號管理後台的「回應設定」開啟 Webhook。若要用本工具的歡迎訊息／自動回覆，請關閉後台內建的「加入好友的歡迎訊息」與「自動回應訊息」。

好友名單：Webhook 開啟後，新加入、傳訊息或點按鈕的好友會自動記錄。舊好友可以按「從 LINE 同步好友名單」匯入（此 API 只開放給認證／進階帳號）。

## 使用方式

- **做多層圖文選單**：圖文選單 → 新增 → 選大／小版面 → 上傳設計圖（或用格子文字產生底圖）→ 拖曳切格並設定動作 → 新增第二層，把要換頁的格子設成「切換到其他層」→ 上架，或設定排程上下架；選「只給特定標籤」即為分眾選單。
- **分眾推播**：訊息與推播 → 編輯訊息 → 推播區選「標籤分眾」→ 選包含／排除標籤 → 送出或排程。
- **看成效**：成效與排程 → 展開推播活動或圖文選單，看每顆按鈕／每一格的點擊。

## 限制

- 個人層級的已讀率 LINE 沒有提供，任何工具都拿不到。
- 推播「全部好友」用 broadcast，點連結只能統計次數，無法知道是誰點的。
- 分享（MGM）只能統計點了分享按鈕的次數，無法歸因到新好友。
- 資料庫是單一 JSON 檔，適合好友數萬人以內的規模。

## 測試

```bash
npm test
```

測試會啟動伺服器並模擬 LINE API，驗證訊息產生、Webhook 簽章、自動貼標籤、分眾推播、追蹤連結、多層圖文選單發布與分眾指派、排程、關鍵字自動回覆。
