# 閒魚指定商品自動下單

你提供商品網址和價格，程式在電腦上核對無誤後自動下單到「待付款」。**付款由你在手機上完成**。

## 流程

```
開商品頁 → 核對：是閒魚商品、還沒售出、價格 ≤ 你給的價格
        → 按「立即购买」→ 在確認頁核對應付總額 ≤ 你給的價格（＋允許的運費）
        → 按「提交订单」→ 停在付款前
你：閒魚 App →「我的」→「我买到的」→「待付款」→ 付款
```

任何一項不符，程式都不會下單，並告訴你原因。商品頁會留著，方便你手動處理。

## 安裝（Windows，只要做一次）

1. 安裝 [Python 3.11 以上](https://www.python.org/downloads/)，安裝時勾選「Add Python to PATH」。
2. 在這個資料夾開啟命令提示字元：
   ```
   pip install -r requirements.txt
   ```
   程式預設用電腦上的 Chrome。如果沒裝 Chrome，就執行 `playwright install chromium`。
3. 登入閒魚：
   ```
   python xianyu_order.py --login
   ```
   在跳出的瀏覽器裡用閒魚 App 掃碼登入，完成後回到命令視窗按 Enter。之後不用再登入，除非登入過期。

## 使用

**下單一件**：

```
python xianyu_order.py https://www.goofish.com/item?id=123456789012 1099
```

**一次下多件**：把 `orders.example.txt` 複製成 `orders.txt`，一行一筆，格式是「網址 價格」，然後執行：

```
python xianyu_order.py -f orders.txt
```

網址可以直接貼閒魚 App「分享 → 複製連結」得到的整段文字，價格放在最後就好。

**其他選項**

| 指令 | 用途 |
|---|---|
| `--check` | 只核對網址和價格，不下單。第一次使用建議先跑這個 |
| `--watch 60` | 價格還沒降到你給的價格時，每 60 秒左右重查一次，符合就立刻下單。按 Ctrl+C 停止 |

## 價格怎麼比

- 商品價格 **≤** 你給的價格才會下單，比你給的便宜也會下。
- 確認頁的應付總額會再核對一次。預設只接受包郵，也就是總額不能超過你給的價格。如果可以接受運費，就複製 `config.example.toml` 成 `config.toml`，把 `max_shipping` 改成你能接受的運費上限。

## 注意事項

- 執行時瀏覽器視窗會打開，請不要關掉。閒魚會擋看不到視窗的瀏覽器。
- 出現滑塊驗證或「非法访问」時，程式會暫停，等你在瀏覽器裡手動處理完再繼續。
- 需要選規格（顏色、容量）的商品沒辦法自動下單，程式會停下來讓你手動處理。
- 下單後不付款，訂單會自動取消。常這樣可能影響帳號信用。
- 用自動化工具操作閒魚可能違反平台規範，帳號有被限制的風險。
- 如果閒魚改版，導致按鈕文字不同，可以在 `config.toml` 加上 `buy_button_texts` 或 `submit_button_texts` 調整，預設值寫在程式的 `Config` 類別裡。
